Crítica

Pasos recomendados para contención:

  1. Pulsa 'Revoke all other web sessions' para cerrar sesiones activas de navegador.
  2. Revisa y revoca Personal Access Tokens (PATs) en Developer Settings > Personal access tokens.
  3. Inspecciona tus SSH Keys en Settings > SSH and GPG keys y elimina claves no autorizadas.
  4. Revisa Authorized OAuth Apps y GitHub Apps autorizadas.
